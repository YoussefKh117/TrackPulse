# Supply Chain & Intelligent Logistics

An Azure-based streaming and batch data engineering project.

## Objectives
- Ingest vehicle telemetry events.
- Detect operational and cold-chain risks.
- Store and process data in a lakehouse.
- Build dimensional models and business intelligence dashboards.

## Technology Stack
- Python
- Azure Event Hubs
- Azure Data Lake Storage Gen2
- Azure Stream Analytics
- Azure Databricks and Delta Lake
- Azure Data Factory
- Azure SQL Database
- Power BI
